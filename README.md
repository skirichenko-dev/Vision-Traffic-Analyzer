# 🚘 Vision Traffic Analyzer

Инструмент аналитики дорожного трафика на базе компьютерного зрения. Проект использует OpenCV для детекции движущихся транспортных средств в видеопотоке в реальном времени.

### 🚀 Возможности
* Детекция движущихся объектов с использованием алгоритма Background Subtraction (MOG2).
* Выделение области интереса (Region of Interest) для снижения нагрузки на процессор.
* Фильтрация оптических шумов на основе площади контуров.
* Легко интегрируется с RTSP-потоками от уличных камер.

### 🛠 Стек
* Python 3.10+
* OpenCV (`opencv-python`)
* NumPy

### 💻 Запуск
Установите зависимости и запустите скрипт:
```bash
pip install opencv-python numpy
python traffic_analyzer.py
